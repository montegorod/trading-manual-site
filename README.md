# Technical Analysis Workbook

A free 69-page self-study guide to technical analysis: 14 chapters, 44 charts,
practice tasks, a checklist and a 66-term glossary. No income promises, no signals.

**Download:** see the [Releases](../../releases) page — `manual-en.pdf`.

## What is inside

1. **Why this workbook exists** — why beginners learn the method backwards.
2. **What technical analysis is** — definition, three postulates, limits.
3. **From rice candles to algorithms** — a short history.
4. **The chart: how to read price** — OHLC, candles, timeframes, sessions, gaps.
5. **Trend and market structure** — HH/HL, BOS/CHoCH, trendlines, channels.
6. **Levels** — why a level is a zone, how to build and test it.
7. **Volume** — what it measures, where it is honest, where it is a proxy.
8. **Reversal patterns** — head and shoulders, double and triple tops, cup and handle.
9. **Continuation patterns and gaps** — triangles, flags, pennants, wedges, gaps.
10. **Candlestick patterns** — pin bars, engulfing, harami, stars, marubozu.
11. **Moving averages** — SMA/EMA, periods, crossovers, filters, ranges.
12. **Indicators without illusions** — RSI, MACD, stochastic, ADX, Bollinger, ATR, A/D, OBV, Aroon.
13. **From analysis to a system** — decision chain, position size, R:R, journal.
14. **Practice, checklist and glossary** — 12 tasks, a checklist, 66 terms.

## How to build it yourself

The book is generated from Markdown:

```bash
pip install -r requirements.txt
python tools/build.py --lang en
```

Everything is in this repository: chapter sources, SVG charts generated by code,
layout, and the build pipeline.
